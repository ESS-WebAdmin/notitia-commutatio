# notitia-commutatio
Data Presentation &amp; Exchange Web Application
It shall: 
- Create a repository of data-source API endpoints searchable by users 
- Organize data logically for users to quickly find using filters
- Allow API data-source end-points be added by users
- Allow users to view data in a variety of customizable charts & tables, as well as perform statistical analysis
- Allow users to create dashboards
- Be written using React and a LAMP stack 

It may: 
- Use Laravel
- Store data for quicker retrieval later
- Implement a variety of different API paradigms dependent on source characteristics
